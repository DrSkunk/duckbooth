# Duckbooth

Native Raspberry Pi photobooth for the Camera Module 3 Wide.

- HDMI-A-2: touchscreen capture flow
- HDMI-A-1: passive newest-20 gallery
- Originals: `/home/booth/photobooth/photos`

The app uses Picamera2 and PyQt5 supplied by Raspberry Pi OS/Debian.

The app starts automatically after the graphical desktop has initialized. Press
`Ctrl`+`Alt`+`Q` to close it deliberately; use the **Start Duckbooth** desktop
shortcut to open it again.
